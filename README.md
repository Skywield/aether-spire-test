# Aether Spire - playtest build (milestone 4)

Prototype web build (Godot 4.7, single-threaded). Play: https://skywield.github.io/aether-spire-test/

Controls: WASD/mouse or gamepad (Backbone / Xbox layout): left stick move, X strike, Y/RB slam, A dodge,
Start tactical pause, B revive. I or pause menu > Gear & bag for loot. Add ?touch=1 for phone touch controls, ?party=0 for solo.
Built from aether-spire/game commit 97b7181.
